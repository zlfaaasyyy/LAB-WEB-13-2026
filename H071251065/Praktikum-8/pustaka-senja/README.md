# Pustaka Senja

Cara memasang:
1. `npx create-next-app@latest pustaka-senja` (JavaScript, ESLint Yes, Tailwind Yes, src/ Yes, App Router Yes, alias @/* default)
2. Hapus `src/app/layout.js`, `src/app/page.js`, dan `src/app/globals.css` bawaan.
3. Salin folder `src/` dari paket ini ke dalam proyek (timpa).
4. `npm run dev` lalu buka http://localhost:3000
